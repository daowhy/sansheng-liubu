# 03 · 运行机制

> 制度立起来之后，靠四个机制转起来：**即开工、收班交割、巡账催办、token 节制**。全部来自两个月真实运营的踩坑沉淀。

## 一、即开工制

**条件满足立即开工，禁延迟性排期说法。** 例外唯二：条件未满足（注明所候何事）、业务节律（循节律）。

配套两条：

- **谕至札出**：谕令、批示涉他衙动作 → 交办文书与执行同拍出件，落卷、投匣、登行三事同轮俱毕，不滞后；
- **当日事当日毕**：能当日办的不写「计划明日办」——「计划」一词在公文里出现的频率，是朝廷健康度的负向指标。

## 二、收班交割（会话续任的命脉）

LLM 会话有寿命，朝廷不能有断档。每班收尾三件事：

1. **收班一行**（当日有动作的衙门）：登公告板，一行说清——本班办了什么、账面是否清、候什么；
2. **交接卷**：在途事项逐条落卷——案号、现态、下一步、所候何人何物。新班开机读交接卷即可续任，不问旧人；
3. **用毕收班**：凡事项毕（批红落定/文书出匣/问答应讫）主动收班提示开新班——长会话既耗 token 又易失忆。

## 三、巡账催办（账不会烂的保障）

- 监察衙门（御史台/吏部）**定期巡账**：扫全衙收文账，逾期未回者出催办单；
- 催办单自动触发：回执账上到期未销即出单，不靠人记性；
- 巡查节奏可精简：周巡足矣，但**不可不巡**——巡账停，回执制名存实亡。

## 四、token 节制三式

朝廷日常运转的隐性成本是 token。三式节制：

1. **收文器输出截断**：只取未回执件清单节，匣内全文按需再读；
2. **读匣头尾＋关键节**：要害件方全文，例行知照读头即可；
3. **用毕收班、新班读账续任**：御览台/总登/回执账在盘，新班启动数千 token 满血，不长会话硬扛。

## 五、精简朝政（文书减负）

制度会自我膨胀，定期瘦身：

- **公告板制**：纯知照类（无动作、无候回）登板不投匣——公告板是「看过即知」，匣是「必须回」；
- **收班一行封顶**：一衙一日一行，倒逼说人话；
- **核点全过即施行**：机检全过的事项不再逐件人工复核，事后抽验兜底；
- **减文不减责**：省的是文书流转量，回执闭环与巡账催办一寸不让。

## 六、事故处置预案（照抄即用）

| 事故 | 处置 |
|---|---|
| 覆写/误删 | 立即停手 → 隔离区找回（移动不删除制度）→ 呈报君主定夺 → 复盘入卷 |
| 越权（该请旨未请） | 先自查自劾 → 监察衙门察责 → 制度补漏（多半是流程含糊，不是人品问题） |
| 会话失忆/僵死 | 收班哨发现静默 → 提示关班 → 新班读交接卷续任 |
| 数字打架 | 刑部三源互证：库实数、官方口径、发布稿逐位对——对不上的以库实数为准并勘误 |

## 七、度量：朝廷健康度三数

每月看三个数就够了：

1. **环闭率**——收文账里「已回」占比（健康线：九成以上）；
2. **逾期件数**——催办单触发数（趋势向上即有衙门病了）；
3. **单日文书峰值**——突然翻倍多半是流程空转，查之。
