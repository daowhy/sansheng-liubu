# 02 · 公文制度

> 一纸公文走天下。本文是公文制的完整规格：三式、四段骨、出件六查、回执账制。全部规则服务于一个目的——**每件事有编号、有收执、有时限、有销行**。

## 一、文书三式

| 式 | 用途 | 结构 |
|---|---|---|
| **甲 · 行文式** | 致实发衙门交办/请办 | 头七行 ＋ 一事由 ＋ 二交办事项 ＋ 三候回与流转 |
| **乙 · 知照式** | 知照圈短体（回执/知悉/报备） | 四行头 ＋ 事由一句 ＋ 本衙须知一条 ＋ 落款 |
| **丙 · 留档式** | 省内存档（不外发） | 头三行即可。但凡外发必转甲式或乙式，不留混发 |

### 头七行（甲式）

```
文书类｜编号：SS→GB-YYYYMMDD-序（发方衙码→收方衙码·日期无横线）
案号：YYYYMMDD-事由-NN（跨衙共案共用案号·各文只载本衙事项）
签发｜收执｜权源（谕令/札付/御批原文）｜随件
```

**编号即身份证**：一衙一文；一事涉多衙按衙分文，共用案号。看到编号就能查到全文、时限与销行去向。

## 二、四段之骨（不可易）

一切衙门间公文与奏对，四段定序：

1. **结论**——一两句报果，要害分析随此。读文的人第一段就该知道发生了什么。
2. **分衙列札**——每札以收件衙门名领句（「工部札＋：」），一望而知何文何往。见衙与事，不见件数统计。
3. **附报**——证据与余波随文。
4. **下步**——对上载候裁；衙门间即候回节。

**候回与流转**（文末必备）：候回事项 ＋ 时限 ＋ 销行去向。知照性文注明「知照性·无候回」。

## 三、出件六查（每件必过·一查不过不出匣）

1. **编号日期**——编号式合规，日期无横线；
2. **头七行**——甲式七行齐；
3. **收执唯一**——一衙一文；
4. **候回节**——文末在；
5. **四段骨**——结论/列札/附报/下步，领句在；
6. **投匣登行**——投收件衙收文目录 ＋ 登发文总登。

六查中前四查与第六查可脚本机检（本文档仓库的出件器即按此实现），第五查人核。**查不过则件不出**——机器替人守住格式底线。

## 四、收文与回执账（回执闭环）

- 来文一律入 `本衙/收文/` 目录存执，不散置衙根；
- **投匣＝发出**：发文时自动记入收件衙收文账，到期＝投匣＋4 小时；
- **回一行已知悉＝送达**：收件方回一行（注明文件名或编号）即销账；
- **开工先跑收文器**：未回执件清单逾期标红，逾期先办；
- 逾期催办单自动触发——**账不会烂在没人看见的角落**。

## 五、公文取名速查

| 文书 | 方向 | 一句话 |
|---|---|---|
| 札付 | 上→下 | 交办令（载事项+时限） |
| 呈 / 题本 | 下→上 | 请办/汇报（候批红） |
| 知会 | 平行 | 告知某事（可载乞办） |
| 回执 | 平行 | 一行知悉/办讫销账 |
| 催办单 | 上→下 | 逾期催办（自动触发） |
| 复验单 | 验方→办方 | 验收结果（过/打回） |

## 六、为什么这么严

公文制的真正价值不在格式好看，在于三件副产品：

1. **可审计**——御史台巡账即知哪个衙门积压、哪类事逾期；
2. **可交接**——会话崩了、人换了，交接卷＋账册在手，新班开机即续任；
3. **可复盘**——两个月五百件公文就是一部运营史，每笔账都能回放。
