# 01 · 朝廷总纲

> 官制三层：**岗位 → 职责 → 工具**。每个衙门是一张职责卡，每个职责卡挂具体工具与产出物，每个产出物落卷宗。本文是立制总纲，岗位实操见 `岗位示例/`。

## 一、立制三策

朝廷治事，三策为纲——这是整套制度的地基：

1. **任命旧人，不设空衙**
   各衙门从现有实际动作中任命，无对应动作者不实设。宁缺毋滥——一个只有名字没有产出的衙门，比没有更糟。

2. **一纸公文走天下**
   所有跨衙协作走统一公文制，不设第二套格式。格式即纪律：编号可查、收执可追、时限可催。

3. **君主亲握关键权柄，余皆可分**
   六权不下放：①对外发布批准 ②付费分文 ③覆盖性变更确认 ④制度修订批红 ⑤删除/隔离处置批准 ⑥官员任命。涉六权一律事前请旨；其余工序各级自主，不逐条请示。

**效力位序**：君主谕令 ＞ 基本家规 ＞ 朝廷总章 ＞ 各部门章程 ＞ 各产线手册。下位与上位相抵者，上位为准；部门章程可严于总章、不得宽于。

## 二、官制表（三省六部 + 御史台）

| 衙门 | 一句话职责 | 核心产出物 |
|---|---|---|
| 中书省 | 立案定标：目标、非目标、验收基线、跨产线取舍 | 立案书 / 规划正本 |
| 门下省 | 审：合规红线、口径矛盾、方案风险 | 审读意见 / 验讫录 |
| 尚书省 | 交付总调度：派工、批红、台账、限期核销 | 御览台 / 总调度账 / 公告板 |
| 吏部 | 典章与技能：文书格式、技能库、能力登记 | 总章 / 格式典 / 技能库 |
| 户部 | 资源与资金产线主管（无支付权，付费唯呈报） | 账册 / 研判 / 报表 |
| 礼部 | 人情往来产线：对外关系、回评、反馈分析 | 运营方案 / 回评记录 |
| 兵部 | 发布纪律与观察：平台规则、判罚观察 | 发布纪律手册 / 观察卷 |
| 刑部 | 独立验证：数字三源互证、核销、复算 | 勘验单 / 复核裁示 |
| 工部 | 技术建设：一切生产施工（内容 / 图文 / 代码 / 系统 / 工具） | 工单 / 交付物 / 施工记录 |
| 御史台 | 察政：事故审计、越权抽查、定期巡查 | 察卷 / 巡报 |

> 衙门设置跟着业务走：以上是参考拓扑，你的朝廷按实际业务裁设。原则只有一条——**以产出物性质定归口**，跨类者主产出定主归口。

## 三、四条通律

1. **审施分离**
   凡审、验、察之职，不得由承办施工之会话兼任。自己写的自己验，等于没验。

2. **归口不替代流程**
   归口系主管事权：流程线照旧——立案走中书、审核走门下、验数走刑部、调度走尚书，一概不因归口而移。

3. **任命之权在君主**
   衙门不得自行任命他衙之官；任命由君主亲授或御批文书指定。到任者具到任文书存本衙。

4. **本尊与分身**
   君主亲自主持之会话为本尊；分身代批者须本尊留痕追认方生效。未追认前，涉事事项禁对外发布、禁覆盖、禁定归档为准。

## 四、一图看懂运转闭环

```
        君主（六权亲握）
           │ 谕令
           ▼
  中书立案 → 门下审核 → 尚书派工（札付+限期）
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
          六部承办        刑部验数       兵部司发布
              │             │
              └──── 工单回执 → 尚书核销 → 公告板登行
                            │
                    御史台巡查（账实相符？逾期？越权？）
```

每一环都有文书、有时限、有回执——**环闭即账清**。
