# 00 · 快速上手

> 一个下午，把朝廷最小可行版（MVP Court）跑起来。先跑通「派活 → 干活 → 交活」闭环，再按需扩衙。

## 第一步：定编（30 分钟）

不要一次设满十个衙门。最小编制三席：

| 席位 | 谁来当 | 先管什么 |
|---|---|---|
| **尚书省** | 你的主力会话 | 派工、台账、核销——所有任务从这进 |
| **工部** | 执行会话（可多个） | 一切产出施工 |
| **御史台** | 独立会话 | 验收与巡账——审施分离，别让工部自验 |

你本人即君主：发布、付费、删除、任命四权留在手里，其余放手。

## 第二步：立三件器（30 分钟）

1. **公文格式卡**：抄 `02-公文制度.md` 的头七行＋四段骨＋候回节，贴进每个会话的系统提示词；
2. **目录骨架**：每个衙门一个目录，下设 `收文/`（来文存执）与卷宗区；
3. **两本总账**：`发文总登.md`（尚书省记）与各衙 `回执账.tsv`（投匣自动记）。

## 第三步：写职责卡（每人 20 分钟）

照 `岗位示例/` 三张卡的格式，给每个席位写一张：**你是谁 / 你管什么 / 你出什么文书 / 你的时限纪律**。职责卡是提示词范式——直接当 system prompt 用。

## 第四步：跑第一单（剩下的时间）

1. 你（君主）对尚书省说：「立项：××。出札派工部，限今日」；
2. 尚书省出札付（甲式）投工部收文目录，登总登；
3. 工部开工读匣 → 办理 → 出回执＋交付物，投回尚书省；
4. 御史台验交付物，出复验单；
5. 尚书省核销登板，你一行批红。

走完这一圈，你就拥有了：编号可查的一件公文、一条回执闭环、一次验收留痕。**此后所有事都照这一圈跑，复杂度只加文书种类，不加新流程。**

## 常见第一周踩坑

| 坑 | 解法 |
|---|---|
| 会话把公文格式忘掉 | 格式卡进 system prompt，出件六查做成脚本机检 |
| 来文堆在聊天里没进匣 | 立规：跨衙事项不见文书不算数（「口头派活无效」） |
| 衙门越设越多全是空壳 | 执行「不设空衙」：两周无产出的衙门裁撤 |
| 回执变成负担 | 回执只须一行知悉——「已知悉（文件名）」六个字就是合法回执 |
