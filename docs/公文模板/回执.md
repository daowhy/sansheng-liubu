# 公文模板 · 回执

> 回执是回执闭环的最小单元——**一行知悉即合法**，办讫报果加结论段。回执的成本必须低到没有借口不回。

## 式一 · 知悉回执（乙式·最简）

```markdown
文书类：回执（乙式知照·知悉）｜编号：〔本衙码〕→〔来文衙码〕-YYYYMMDD-序｜案号：〔来文案号〕｜
签发：〔本衙〕 · 日期｜收执：〔来文衙〕｜权源：〔来文编号〕｜随件：无

〔来文编号〕**已知悉**（〔文件名〕）。〔本衙须知一事·如涉及则一句话，无则删此句〕。

候回与流转：知照性·无候回｜销行：本件投贵衙收文匣·登本衙发文总登（来件随销）。

——〔本衙〕
```

## 式二 · 办讫回执（乙式·带结论）

```markdown
文书类：回执（乙式知照·施讫报）｜编号：〔本衙〕→〔收执衙〕-YYYYMMDD-序｜案号：〔案号〕｜
签发：〔本衙〕 · 日期｜收执：〔收执衙〕｜权源：〔交办文书编号＋御批/谕令原文〕｜随件：无

# 〔衙门〕回执 · 〔事由〕办讫

**结论**：〔一两句报果——做了什么、验了什么、现态如何〕。

**〔验收/明细段〕**：〔关键数据、实测输出、URL、回退方法——证据随文〕。

**附报**：〔余波与相关发现·如无删〕。

**候回与流转**：知照性·无候回｜销行：本件投贵衙收文匣·登本衙发文总登（来件随销）。

——〔本衙〕
```

## 回执四纪律

1. **四小时为限**：知悉回执越快越好，最迟当日；
2. **编号必注来文**：销行去向写清「来件随销」，账才闭环；
3. **办讫必带证据**：实测输出/URL/数据，不写「应该没问题」；
4. **回退必写**：涉及系统变更的，回退方法三行内写清。
