# 公文模板 · 收班交割

> 每班收尾必做。交接卷是会话续任的命脉——新班读卷即续任，不问旧人。

## 收班一行（登公告板·一衙一日一行封顶）

```markdown
YYYY-MM-DD｜〔衙门〕｜收班：本班办讫〔事项A／事项B〕；账面〔清／有未回 N 件（所候：××）〕；
候项：〔事项C 所候何人何物〕 🌙
```

## 交接卷（本衙交接卷追加一节）

```markdown
## 交接 · YYYY-MM-DD 〔班次〕

| 事项 | 现态 | 下一步 | 所候 |
|---|---|---|---|
| 〔案号/事项名〕 | 〔进行到哪一步·关键数据/路径〕 | 〔接手第一动作〕 | 〔何人批红/何方供数/何时窗口〕 |

### 环境与凭据变更（如有）
- 〔新增/变更/作废的路径、配置、凭据位置——凭据只写位置不写值〕

### 本班教训（如有）
- 〔一句话：什么坑、怎么避——供下班与新衙参考〕
```

## 三条纪律

1. **现态写到「接手人不用问旧班」的颗粒度**——路径、数值、版本号写全；
2. **所候必须具名**——候谁的批红、候哪方的数据、候哪个日期的窗口；
3. **凭据零明文**——只写「在某某库某文件」，值永不入卷。
